# Muhammadali Haitboyev - Modern & Soft Portfolio Website

Welcome to the personal portfolio website for **Muhammadali Haitboyev**!

This portfolio is designed with a **modern, soft UI aesthetic** featuring gentle pastel ambient lighting, frosted glassmorphism, fluid typography, dark/light theme switching, and an interactive **live 16-puzzle (Pazle 16) playable game**.

---

## 🌟 Key Features

1. **Clean & Soft Design Language**:
   - Soft shadows, pastel gradients, rounded pill badges, and clean contrast.
   - Built-in **Dark / Light theme switcher** with state persistence (`localStorage`).
   - Ambient background glow effects.

2. **Interactive 16-Puzzle Game (Pazle 16)**:
   - Playable directly on the website.
   - Includes real-time stopwatch, move counter, 100% solvable shuffle algorithm, victory detection, and celebration banner.

3. **Featured Projects Showcase**:
   - **Pazle 16 Game**: Algorithmic sliding puzzle.
   - **SkyCast (Weather App)**: Real-time weather forecasting with dynamic icons.
   - **ValutaPay (Currency Converter)**: Instant multi-currency calculations.
   - **Lug'at (Smart Dictionary)**: PHP & database powered vocabulary search with audio pronunciation.
   - **TaskFlow & Portfolio v1**: Additional fullstack & frontend showcases.
   - Dynamic category filtering (`All`, `React`, `JavaScript`, `PHP / Fullstack`, `Games`).
   - Interactive project detail modal for in-depth technical breakdowns.

4. **Tech Stack & Skills Matrix**:
   - Visual proficiency indicators for HTML5, CSS3, JavaScript (ES6+), React.js, PHP, MySQL, REST APIs, Git, and Responsive Design.

5. **Direct Contact System**:
   - Interactive contact form.
   - One-click **Copy Email** button with toast notification.
   - Links to Telegram, GitHub, and Email.

## 🚀 How to Run & Customize

### To view locally:
Simply double-click `index.html` to open it in any browser (Chrome, Edge, Firefox, Safari).

### To customize details:
- **Email & Telegram**: In `index.html` and `script.js`, replace `alialiyevuz61@gmail.com` and `@Muhammadali_Haitboyev` with your actual handles.
- **GitHub profile**: Replace `https://github.com/Muhammadali2422` with your direct profile link.
- **Photos / Avatar**: You can replace the MH initials badge in `index.html` with an `<img>` tag of your profile photo if desired.
